## 3. UPGRADE RULE

An application does not supersede its engine. A trial may add required revisions to the next orchestration layer without silently editing the source engine. A newer canon supersedes an older canon only where it explicitly says so. Mapping references describe connections; governance decides authority. Generated views never replace canonical objects.

## 4. THE FULL RUN

```text

   discrimination, and emergent role.

   bridge/IC grade, and resolution state.

11. TRANSLATE only between fully opened native objects.
12. SEPARATE Native result, Bridge mapping, and Christian Identification.
13. BUILD the answer packet and preserve OPEN burdens.
14. HUMAN RULES candidate admission, correction, withdrawal, or return.
15. PROJECT canonical objects into JSON-LD, HTML, papers, and teaching views.
16. LOOP every correction and new question back to Step 0.
```

## 6. WHAT “NON-DISCRIMINATORY” MEANS

It means the same questions, decomposition rules, rival strength, evidence burdens, and closure tests apply before the system knows which answer David prefers. It does not mean all answers are equally good, all registers use identical evidence, or Christian theology is excluded. Theology enters plainly at its native and identification layers after the neutral discovery record is preserved.

## 7. THE FINAL SYSTEM CLAIM

This system does not promise that every question will close. It promises that every answer will reveal:

- what was asked;
- which burdens the question contained;
- what objects answer them;
- what was proved, observed, inferred, confessed, or merely mapped;
- what rivals remain;
- where translation holds and fails;
- what wording is licensed;
- and exactly where knowledge remains open.

## 8. ONE-SENTENCE VERSION

**Ask without loading the answer, open every burden, store every result in its native object type, classify only after discovery, translate only through tested structure-preserving bridges, identify theology without laundering it, and let the admitted graph say exactly as much—and only as much—as the total evidence can carry.**
