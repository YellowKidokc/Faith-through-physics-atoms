## 0. THE TWO RESPONSIBILITIES (Governance)

This project holds two duties at once, and the pipeline exists to keep both: (1) determine whether the deep structures of the domains can be related in one coherent account of reality; (2) never silently collapse their differences. Every stage below serves one of these duties. A stage that serves neither is removed. A stage that serves the first while betraying the second is the failure mode the whole grammar exists to prevent.

---

## 1. THE PIPELINE — ONE DIAGRAM

```
RAW INTAKE → BLIND DISCOVERY → BLIND RECONSTRUCTION → CONVERGENCE CHECK
→ WHY-CLOSURE GATE → EMERGENT CLASSIFICATION → RECONCILIATION
→ ROOT-CONDITIONED PASS (optional) → COUNTERMODEL GAUNTLET → ADMISSION & STORAGE
→ GOVERNANCE & CORRECTION → (loop: every correction re-enters at RAW INTAKE)
```

Each stage depends on the prior, preserves it, and adds exactly one capability. The pipeline is itself a DG instantiation: no skips (T1), collapse propagates (T2), translation preserves structure (T3).

## 2. STAGE BY STAGE

### STAGE 0 — RAW INTAKE (Blind Reconstruction §3)
Preserve the original. Hash it. Never rewrite, rename, merge, or delete a source record during analysis. Record the raw statement verbatim before clarification (BFP-DG Q0). The original identifier survives every later decomposition and rerun.
**Output:** immutable source manifest, hash-pinned.

### STAGE 1 — BLIND DISCOVERY, forward (BFP-DG Q1–Q14)
Ask the fixed category-neutral questions: what is picked out; what makes it this rather than not-this; what it requires for formulation, coherence, existence; what varies and what must remain; what it does and undergoes; what connects states; what limits possibilities; what follows if granted (every arrow names its license); representation ladder with the formalization boundary; what reality looks like if true AND if false; what evidence discriminates. No inherited labels. No domain names. No preferred conclusion.
**Output:** identity kernel, dependency floor, operation signature, constraint structure, representation ladder, truth-space, countermodel candidates.

### STAGE 2 — BLIND RECONSTRUCTION, reverse (BFP-DG B0–B8)
From observed content back toward candidate grounds: pattern → invariant → operation → constraints → dependencies → minimal structure → candidate ground class → competing ground classes. Every step's inference is typed: deductive / inductive / abductive / statistical / analogical / underdetermined. The reverse pass yields a SET of candidate grounds — never a forced answer.
**Output:** candidate ground classes with typed inference chains.

### STAGE 3 — CONVERGENCE CHECK (BFP-DG §6)
Top-down signature D(r) meets bottom-up candidates R(s) at the domain-neutral invariant signature — identities, distinctions, relations, operations, dependencies, constraints, invariants, collapse conditions, consequences — compared WITHOUT names. Minimal convergence: r ∈ R(D(r)). Unique recovery: R(D(r)) = {r} — and unique recovery must never be claimed when several roots generate the same signature. Underdetermination is a result, not a failure.
**Output:** convergence verdict with the invariant signature.

### STAGE 4 — THE WHY-CLOSURE GATE (BFP-DG §7)
Every convergence faces: why did this work rather than fail or take another form? The why-ladder (descriptive, mechanistic, structural, boundary, historical, grounding, purposive — mark inapplicable levels, never skip silently). Every answer typed (logical necessity … selection effect … coincidence). The non-restatement test. The pattern-match pressure test: construct a rival match, remove the labels, permute the pairings, measure whether the preferred mapping has a real advantage. Outcomes: WHY_CLOSED (with closure level reported) / WHY_FAILED / WHY_OPEN — and WHY_OPEN is a positive finding, preserved with its rivals and its next discriminating test, never silently converted.
**Output:** closure outcome per convergence.

### STAGE 5 — EMERGENT CLASSIFICATION (BFP-DG §4)
Labels emerge now and only now: DECLARATION, DEFINITION, AXIOM, BOUNDARY_CONDITION, INFERENCE_RULE, LEMMA, THEOREM, MODEL, INTERPRETATION, BRIDGE, ANALOGY, EMPIRICAL_CLAIM, PREDICTION, PROTOCOL, THEOLOGICAL_REGISTER, OPEN_STATUS. A record may carry several labels on different axes. Analogy is never promoted to identity. Interpretation never inherits theorem status.
**Output:** classified record.

### STAGE 6 — RECONCILIATION (Blind Reconstruction Pass Two)
Reveal the inherited labels, declared dependencies, and source history — and compare against what discovery found. Agreement is typed: confirm / partial_match / conflict / missing_from_source / unsupported. Declared dependencies are evidence about authorial intent, not proof an edge is valid. Conflicts are preserved, not resolved by preference.
**Output:** reconciliation report.

### STAGE 7 — ROOT-CONDITIONED PASS (optional; Blind Reconstruction §6)
If a root (A0) is admitted: for every record — ENTAILED_BY_ROOT / ENTAILED_BY_ROOT_PLUS_PREMISE / COMPATIBLE_NOT_DERIVED / INDEPENDENT_FORMAL_TRUTH / INDEPENDENT_EMPIRICAL_INPUT / CONTRADICTS_ROOT / DOWNSTREAM_CYCLE / FAILS_REGARDLESS_OF_ROOT / UNRESOLVED. This pass tests conditional coherence; it does not prove the root.
**Output:** grounding verdicts with added premises named.

### STAGE 8 — THE COUNTERMODEL GAUNTLET (CNS-03 kill gate + the 2026-08-25 live method)
Formalize what can be formalized (Lean 4). Build the strongest countermodel yourself — the version of the opposition you would least like to face. Pre-register kill conditions. Run negative controls. Preserve every corpse with its lesson. Gold-ticket receipts: compiled locally, exit code 0, zero sorry, hash-pinned, what-checked vs what-not-proved explicit. The claim manifest, warrant ledger, rival constructions, and honest blanks follow the CNS-03 format. Withdrawals are printed where claims were printed.
**Output:** theorems with receipts, counterexample gallery, kill-condition register.

### STAGE 9 — ADMISSION & STORAGE (Consilience Atlas)
Candidate graph and admitted graph are separate — always. Nothing enters the admitted graph without passing its gate and receiving a human ruling. Typed edges only. Classify once, store canonical objects, compute deterministically, project many ways. No wording treats C as a χ factor; the wrapper stays the wrapper.
**Output:** atlas entries with grades, edges, and provenance.

### STAGE 10 — GOVERNANCE & CORRECTION (Governance manual)
The human rules the corpus; no automated run canonizes. Corrections are printed where claims were printed; nothing is silently edited; nothing is deleted — quarantine with a flag. Versioning is public. Every correction re-enters the pipeline at Stage 0.
**Output:** the living canon, with its full correction ledger.

## 3. THE CHARACTER OF THE METHOD (Fruits layer)

The methodology has a character requirement, and it is structural, not decorative. Correction without kindness becomes cruelty; rigor without patience becomes premature closure; power without gentleness becomes domination of the evidence. The Fruits grammar supplies the constraint set under which correction remains restorative rather than destructive [Fruits §1–§4]: truth refuses to rename a wrong result as right; faithfulness refuses to abandon a claim merely because testing it became costly; self-control prevents the auditor's confidence from becoming the auditor's bias. The pipeline corrects the way love restores: preserving the capacity, naming the damage, never pretending the damage was the design.

## 4. THE FAILURE MODES (master list, unified)

- Definitions containing the desired conclusion
- Inherited labels determining the analysis
- A symbol mistaken for a proof
- Dependency mistaken for inference
- Interpretation inheriting theorem status
- Analogy promoted to identity
- Reverse reconstruction forced to recover the chosen root
- Rivals written weaker than the preferred view
- Many-to-one recovery reported as unique
- A correspondence treated as its own explanation
- WHY_OPEN reported as proof or disproof
- A counterexample deleted instead of preserved
- A specification mistaken for a theorem (the Books lesson)
- A selection criterion written after the pattern was seen (the Shadow lesson)
- A probability number attached to a correspondence (the 10⁻³⁴ lesson)
