FORMAL INFORMATION ARCHITECTURE

One envelope. Many object types. Explicit epistemic boundaries.

This atlas separates an object's type from its workflow stage. A claim is not evidence; evidence is not proof; a Lean receipt is not an empirical bridge; and a rendered page is not canon admission.
