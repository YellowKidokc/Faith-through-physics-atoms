# AtlasRecord v1 Vertical Slice

This repo now carries the shared record contract for the proposed stack:

```text
Nabla
  -> Argument Compiler
  -> The Meta-Argument
  -> Atlas
  -> AXIOM-REACT
```

The contract is `_schema/atlas_record_v1.schema.json`.

The first gold specimen is generated by:

```powershell
python _scripts/build_atlas_record_v1.py
```

Default output:

```text
gold/master-equation/atlas-record-v1.master-equation.trilemma.json
```

## Ownership

Each subsystem fills only the fields it owns:

| System | Owned fields |
| --- | --- |
| Nabla | `nabla` semantic address, routing hints, artifact classification |
| Argument Compiler | `atom_stack.claims`, `atom_stack.components`, `evidence_receipts`, `atom_stack.tests`, `edges` from source ingestion |
| The Meta-Argument | `computed.meta_scores`, deterministic audit, veto, confidence, dependencies |
| Atlas | `periodic15`, `atom_stack.dynamics`, `bridges`, `anchors`, `reality_mirror`, graph signature |
| AXIOM-REACT | rendering and interrogation of the shared JSON |

## Non-Negotiable Boundaries

- Native grade is not meta score.
- The atom stack is the local canonical unit; Paper, Series, and Global are aggregations of atom stacks.
- Reality Mirror is a top-level constraint-facing block, not Marker 16 and not a child of `periodic15`.
- Candidate and Admitted must remain separate.
- Source spans and provenance are required.
- Bridge declarations do not promote native grade without independent warrant.
- Marker 4 contains admitted bridge targets only; proposed bridges remain visible in `bridges[]` as candidates.
- Marker 12 is the evidence grade computed from native grade through `_atlas/grade-registry.json`.
- Algebraic support does not establish historical instantiation unless separately evidenced.

## Current Slice Status

The Master Equation trilemma specimen is filled from the local Lane 4 atom and Atlas registries.

The named `argument-compiler` and `the-meta-argument` repos are not local checkouts, but their remote contracts were inspected on 2026-08-11. Argument Compiler is still a foundation-stage draft. The Meta-Argument has a real deterministic engine and JSON schemas, but its atomic-case contract is currently shaped for historical events, laws, policies, institutions, technologies, and public actions. The formal Master Equation claim cannot enter that contract without a typed adapter.

The exact cross-repo field audit is recorded in `_docs/ATLAS_RECORD_V1_ADAPTER_AUDIT.md`. Native outputs that have not actually run remain explicit adapter slots in `audit.subsystem_receipts` and `unresolved`.
