## Reader-facing spine

The public path should not recite the tree. Its initial movement remains:

> Every argument begins somewhere. No one begins from nowhere. If every account
> must begin, what could deserve to be called the beginning? This project answers:
> **God Is.** It then accepts the burden of distinguishing what has been admitted
> from everything still to be identified, disclosed, derived, tested, or lived.

## Implementation boundary

If approved, implementation must be copy-first and reversible:

1. inventory the existing Axiom tree;
2. preserve the current files in place or as verified source snapshots;
3. create the target folders and MOCs;
4. map source passages into candidate destinations without deleting originals;
5. create claim-level crosswalks;
6. obtain human rulings for ambiguous placements;
7. verify hashes and links; and
8. issue a receipt.
